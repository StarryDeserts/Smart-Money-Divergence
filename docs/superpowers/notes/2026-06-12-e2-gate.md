# E2 — GO/NO-GO Gate (data 2026-06-12, run 2026-06-15)

**Purpose:** the project's hinge (plan Phase 4). Run the Phase-3 harness on the
*real* cached universe and decide — against the spec §10 bar — whether to proceed
to the live Skill (Phase 5+) or pivot.

**Tier:** AMBER (per [E1](2026-06-12-e1-data-availability.md)) — price (CoinGecko)
+ fear_greed (CMC) + momentum (derived). **No capital side** (hero whale flow and
funding/OI unavailable on the free key), so the rule runs in crowd-contrarian mode
`D = −crowd_score`.

**Universe:** BTC, ETH, SOL, BNB, DOGE — 365 daily rows/token, overlap
`2025-06-13 .. 2026-06-11`. Split 0.65 → 237 in-sample / 128 out-of-sample
portfolio days. θ_abs = 1.444 (calibrated in-sample only, quantile 0.8).

## Reading the result

1. **Out-of-sample, the rule beats buy-&-hold on every risk axis** — return
   (−4.5% vs −22.9%), drawdown (−5.9% vs −27.5%), and Sharpe (−0.63 vs −0.84).
   The OOS window is a broad crypto drawdown; crowd-contrarian divergence sat the
   portfolio out of most of it. **This is risk reduction, not alpha** — the
   absolute OOS return is still negative.
2. **Long-only dominates long/short.** Shorting roughly doubles turnover (3.6 vs
   2.0) and halves in-sample Sharpe (0.26 vs 0.92) without improving OOS. Ship
   long-only; keep short as a documented ablation.
3. **Attribution is honestly thin.** Only momentum + fear_greed carry signal, and
   both contributions are ~0. The edge is *avoiding the benchmark's drawdown*, not
   a strong directional call. This is exactly what Amber predicts: the
   differentiator (on-chain whale axis) is missing, so there is no large signed
   driver to point at.
4. **In-sample is much stronger than OOS** (Sharpe 0.92 → −0.63). Consistent with
   a thin, defensive edge that partly reflects the calm in-sample regime — not
   over-fit (θ is one global in-sample number, signals are causal), but not robust
   alpha either.

## Verdict: **CONDITIONAL GO (Amber)**

Against the spec §10 / plan Task-16 bar:

- Not a clean **GO**: the hero/edge signal carries no attribution (it is absent),
  and OOS return is negative, so this is not "beats buy-&-hold risk-adjusted *with*
  an explainable edge signal."
- Not **NO-GO**: the result is *not* indistinguishable from noise and *does* carry
  explanatory value — OOS drawdown is 4.7× smaller than buy-&-hold with higher
  Sharpe, and the behavior is fully explained by the crowd-contrarian mechanism.

So it lands in **Conditional GO** (acceptable per spec §C1): the *framework* is
sound, causal, and explainable; the value on this key is the honest framework plus
a real "divergence keeps you out of trouble" **risk-reduction** finding — not magic
PnL. **Proceed to Phase 5**, with the narrative leading on method + honesty and the
report foregrounding the negative/limit findings.
